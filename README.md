# SkillMatch

SkillMatch é uma aplicação simples para comparar o perfil de um candidato com vagas de TI e mostrar quais oportunidades têm maior compatibilidade.

## O que a aplicação faz

- coleta informações como área, experiência e habilidades;
- compara o perfil com as vagas disponíveis;
- mostra o nível de compatibilidade para cada vaga;
- destaca a melhor oportunidade;
- salva os dados no navegador para a próxima visita.

## Tecnologias

- HTML
- CSS
- JavaScript
- JSON
- localStorage
